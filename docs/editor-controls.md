# エディタの操作方法

エディタの Scene パネル（シーンビュー）と、Header の操作方法をまとめたリファレンス。操作やショートカットを追加・変更したときは、このファイルも更新する。

- 対象: Scene パネルの 3D 表示（シーンビュー）での、マウス・トラックパッド・キーボードの操作
- 確認済みの環境: Mac の Chrome・Safari
- キーの表記は、Mac を先に、Windows・Linux を後ろに併記する（Option(Alt)、Cmd(Ctrl)）
- 設計の詳しい仕組みは [architecture.md](./architecture.md) を参照

## シーンビューのカメラ

| 操作                                                | 動作                                   |
| --------------------------------------------------- | -------------------------------------- |
| 右ドラッグ                                          | 見回し（その場でカメラの向きを変える） |
| 右ボタンを押している間の W / S                      | フライスルー: 前進 / 後退              |
| 右ボタンを押している間の A / D                      | フライスルー: 左 / 右                  |
| 右ボタンを押している間の Q / E                      | フライスルー: 下降 / 上昇              |
| 右ボタンを押している間の Shift                      | フライスルーを速くする                 |
| 中ドラッグ                                          | パン（画面の上下左右に平行移動）       |
| Option(Alt)+Cmd(Ctrl)+左ドラッグ                    | パン                                   |
| マウスのホイール、トラックパッドの 2 本指スクロール | ドリー（前後に移動）                   |
| トラックパッドのピンチ                              | ドリー（広げると近づく）               |
| Option(Alt)+左ドラッグ                              | オービット（注視点のまわりを回る）     |

### 補足

- 注視点: 初期は原点。見回しやフライスルーの後は、カメラの前方の同じ距離に移る。ドリーで注視点に寄りきっても、注視点ごと前に進める
- フライスルーのキーは、右ボタンを押している間だけ効く。右ボタンを離しているときは、W/A/S/D/Q/E でカメラは動かない
- 入力欄にフォーカスがあるときは、キーでカメラは動かない
- シーンビューを押すと（どのボタンでも）、入力欄のフォーカスが外れる
- タッチ操作には対応していない（マウスとペンが対象）。トラックパッドで見回すときは、2 本指で押し込んだまま動かす（右クリック相当）
- シーンビューの上では、右クリックのメニューやページのスクロールは出ない

## 選択とギズモ

- mesh を持つ物体（床を除く）を左クリックで選べる。この条件は暫定で、変わることがある（実装は `app/src/scenesGl/SceneDev.tsx` の `isSelectable`）。何もない所をクリックすると、選択が外れる
- 右・中ボタンと、Option(Alt)+左ボタン（Option(Alt)+Cmd(Ctrl)+左ボタンを含む）のカメラ操作では、選択は変わらない（選択も解除もされない）
- 選択したオブジェクトに出るギズモ（矢印）を、Option(Alt) を押さずにドラッグすると移動する。ドラッグを終えたときに、移動が 1 回の編集として履歴に積まれる（Undo/Redo の対象）
- ギズモの上で Option(Alt)+左ドラッグすると、ギズモではなくカメラ操作（オービット）が優先される。Option(Alt)+Cmd(Ctrl)+左ドラッグのときは、オービットではなくパンになる
- ギズモをドラッグしている間は、新しいカメラ操作は始まらない（ホイールのドリーも効かない）

## Undo / Redo

| 操作                           | 動作 |
| ------------------------------ | ---- |
| Cmd(Ctrl)+Z                    | Undo |
| Cmd(Ctrl)+Shift+Z、Cmd(Ctrl)+Y | Redo |

- 入力欄にフォーカスがあるとき、IME の変換中、Option(Alt) を押しているときは効かない
- 実装は `app/src/hooks/useUndoRedoShortcuts.ts`

## ツールバー（Header）

- 元に戻す・やり直すのアイコンボタン: Undo / Redo と同じ。戻せる履歴がないときは押せない
- 「グリッド」のスイッチ: シーンビューのグリッドの表示・非表示を切り替える
- 「Home」「Menu」は仮の表示で、操作はまだない

## 開発者向け: 速度・感度の定数

カメラの速度や感度は、次のファイルの定数で決める。値を変えるときはここを直す（値はソースを参照）。

`app/src/components/webGl/editorCamera/editorCameraRig.ts`

| 定数                  | 意味                                                      |
| --------------------- | --------------------------------------------------------- |
| `FLY_SPEED`           | フライスルーの速度（単位/秒）                             |
| `FLY_FAST_MULTIPLIER` | Shift を押しているときの速度の倍率                        |
| `LOOK_SENSITIVITY`    | 見回しの感度（rad/px）                                    |
| `ORBIT_SENSITIVITY`   | オービットの感度（rad/px）                                |
| `MIN_DISTANCE`        | 注視点までの最小距離                                      |
| `WHEEL_DOLLY_RATE`    | ホイール・スクロールのドリーの係数（px あたり）           |
| `PINCH_DOLLY_RATE`    | ピンチ（ctrlKey 付きの wheel）のドリーの係数（px あたり） |

- パンの速度は、注視点までの距離と画角から、画面上の 1px に合うように計算する（定数はない）
- `app/src/components/webGl/CameraControl.tsx` の `MAX_DOLLY_EXPONENT` は、1 イベントあたりのドリーの変化量の上限
- 操作の割り当て（どのボタン・修飾キーで何をするか）は `app/src/components/webGl/editorCamera/cameraGesture.ts` の `resolveCameraGesture`
- 初期のカメラ位置は `app/src/scenesGl/SceneDev.tsx` が `CameraControl` に渡す
