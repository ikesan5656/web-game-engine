品質担当として、プロジェクトの品質チェックを実行してください。

このプロジェクトにはテストフレームワークがなく、以前からある lint・型エラー（`SceneDev.tsx`、`GltfModel.tsx`、`MMDModel.tsx` など）が残っています。そのため、**依頼で渡された変更ファイルに関するエラーだけ**を判定対象にします。変更ファイルが渡されていない場合は `git status --short` と `git diff --name-only` で特定してください。

1. lint: `pnpm --dir app exec eslint <変更したファイル>`（`app/` からのパスで指定）
2. 型チェック: `pnpm --dir app exec tsc -b`。既存エラーのため終了コードは常に 1 になるので、出力に変更ファイルの行があるかで判断する
3. 変更ファイルにエラーがなければ「問題なし」と一言だけ報告する
4. エラーがあれば、根本原因と該当ファイル・行番号だけを抽出して報告する（生のログ全文は出力しないこと）。変更していないファイルのエラーは報告に含めない
